# NLB-P02 captures

All captures are engineering UI evidence from Godot 4.7.2 on the local desktop. Host invitation secrets are redacted. The client view shows the manual join fields with no access code present and the waiting-for-host-approval message. It does not prove Wi-Fi or Android behavior.

- `host-lobby-active-redacted.png` — active host, selected interface and actual ports; invitation is redacted.
- `host-lobby-seats-redacted.png` — host seat/readiness panel and disabled network start gate.
- `client-awaiting-approval.png` — client manual address and separate access-code entry, waiting for approval.
- `invitation-test-invalid.png` — synthetic test QR with a documentation-only invalid address and dummy credential, independently decoded.
