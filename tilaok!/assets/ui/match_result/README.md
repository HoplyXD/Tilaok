# assets/ui/match_result

Art for the Final results (winner) screen, built from the team Figma frame "Winner Results" (100:77). Name files ui.match_result.<element>.<ext> and register every file in docs/ASSETS.md before it ships.

- ui.match_result.vine.svg: the frame's "Deco Line" vine (layer 100:84), imported at svg/scale 1.8. It is the Round result vine's drawing at 1.24x, kept as its own file so it renders sharp at this size.

Empty art slots: `ui.match_result.winner_banner` (Art_Background) and `ui.match_result.chalkboard` (Art_Chalkboard). The board, title and buttons use Theme StyleBoxes shared with the Round result and Pause screens.
