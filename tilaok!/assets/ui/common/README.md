# assets/ui/common

Drop final art for the common screen here (PNG for raster, SVG for icons).
Name files ui.common.<element>.<ext> and assign them in the Godot inspector to the matching Art_<Element> node.
Register every file in docs/ASSETS.md before it ships.
Holds ui.common.vine_divider.svg (the team's Figma "Deco Line" vine, used on the Round result). Everything else still uses flat Theme StyleBoxes (PLACEHOLDER).
