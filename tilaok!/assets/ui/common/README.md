# assets/ui/common

Drop final art for the common screen here (PNG for raster, SVG for icons).
Name files ui.common.<element>.<ext> and assign them in the Godot inspector to the matching Art_<Element> node.
Register every file in docs/ASSETS.md before it ships.

- ui.common.vine_divider.svg: the team's Figma "Deco Line" vine, used on the Round result.
- ui.common.menu_pointer.svg: the "Selection pointer" from the Figma "Menu actions" frame (103:570), shown left of the selected menu action button.
- ui.common.icon_play.svg: Lucide "play" icon as placed in the same frame (ISC, see LUCIDE_LICENSE.txt), the Title's Play entry.

Everything else still uses flat Theme StyleBoxes (PLACEHOLDER).
