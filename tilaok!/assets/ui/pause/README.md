# assets/ui/pause

Art for the Pause screen, built from the team Figma frames "Pause Menu" (5:44) and "Pause Menu (With Warning)" (5:81). Register every file in docs/ASSETS.md before it ships.

- ui.pause.panel.png: Figma 2.7x render of the paper layer (5:67) with its drop shadow, torn-edge texture and grain. The export came back on white; transparency was recovered (shadow = black at its grey level, paper opaque).
- ui.pause.pill_glass.png: the pills' Figma glass look as a white highlight overlay, measured from the Figma render so it can sit on any seat colour.
- ui.pause.vine.svg: the frame's "Deco Line" vine (a different drawing from ui.common.vine_divider).
- ui.pause.icon_resume.png / icon_settings.png / icon_library.png: image fills from the frame (source and licence to confirm).
- ui.pause.icon_leave.svg: Iconoir "transition-left-solid" (MIT, see ICONOIR_LICENSE.txt).
